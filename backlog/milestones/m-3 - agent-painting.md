## Description

Agents paint in the running app through the same brush engine people use, at the token cost of writing a generator script: JSON batches of commands read from a file or stdin (decision-8), one undo step per named pass, the canvas updating as they work, cheap feedback (region previews, color samples), help and MCP guidance on the cheapest way to work, and brushes that look like oil (bristles, wet paint). Research: doc-3. Paint thickness (impasto) is m-4.
